# 🩺 Diabetes Prediction System using Machine Learning Algorithms

A machine learning–based diabetes prediction system designed to assist in early detection by analyzing patient health parameters.

---

## 📌 Project Overview

Diabetes is a chronic disease that requires early diagnosis for effective management. This project applies **machine learning techniques** to predict whether a patient is diabetic or non-diabetic based on medical attributes such as glucose level, BMI, age, and blood pressure.

The system is developed as an **academic machine learning project** and demonstrates the practical use of data preprocessing, model training, and performance evaluation.

---

## 🎯 Objectives

* To analyze medical data related to diabetes
* To build a reliable machine learning prediction model
* To assist in early detection of diabetes
* To compare performance of different ML algorithms

---

## 📊 Dataset

* Dataset: **PIMA Indians Diabetes Dataset**
* Source: Kaggle / UCI Machine Learning Repository
* Number of features: 8 medical attributes
* Target variable: Diabetic (1) / Non-Diabetic (0)

---

## 🧠 Machine Learning Models Used

* Logistic Regression

* K-Nearest Neighbors (KNN)

## ▶️ How to Run

   ```bash
   git clone https://github.com/your-username/diabetes-prediction-ml.git
   ```
2. Navigate to the project directory:

   ```bash
   cd diabetes-prediction-ml
   ```
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
4. Run the model:

   ```bash
   python diabetes_prediction.py
   ```
